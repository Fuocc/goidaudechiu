# Moving a whole Group gives every guest the same start time

When staff or the AI move a Group with "Cả nhóm", every guest gets the same new start time and keeps their own service length, so end times may differ. A date-only change keeps each guest's own start time. We chose this over keeping each guest's offset (the older staff behaviour) because a Group arrives together: staggered times usually come from one guest being moved alone, and a Group move is how staff bring them back together. Guests who should stay staggered are moved with "Chỉ khách này".

## Considered Options

- **Keep each guest's offset** (A 14:00 / B 14:30 → A 16:00 / B 16:30): rejected. It keeps old staggering that was usually accidental, and it disagreed with the AI and check-in, which already align start times.
